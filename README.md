# Orbit releases

Downloads and updates for [Orbit](https://browsewithorbit.com), a browser for the Mac.

- The latest version: <https://updates.browsewithorbit.com/download>
- Every version is under [Releases](../../releases). Each disk image is signed and notarized.
- `appcast.xml` is the feed Orbit reads to update itself. It is signed; do not edit it by hand.

Requires macOS 13 or later on Apple Silicon.

Questions and crash reports: hello@browsewithorbit.com
